# 公网隧道（dsh-tunnel）

把本机 DSH 通过 frp 隧道发布到一个**固定公网 HTTPS 地址**，让手机「填地址 + 访问密钥登录一次」后长期使用。

## 它负责什么

- **DSH 信任配置**：把公网域名写进 profile 的 `connection.trustedHosts`，并调长 `cookieMaxAgeDays`（默认 30 → 3650 天）。写入通过 DSH 官方配置编辑器完成，重写时会连同 `trustedHosts` 一起写回，不会因为覆盖行配置而让公网地址失信。
- **frpc 托管**：每次 DSH 启动后读取真实监听端口，生成 frpc 配置，拉起并守护 frpc；崩溃退避重启，DSH 退出时一并停止。
- **手机登录信息**：展示固定服务地址与当前进程的访问密钥（默认隐藏、可复制），并标注「仅当前进程有效、泄露等于整机控制权」。
- **可迁移**：配置可导出为不含任何密钥的 JSON，换电脑导入即可；卸载有明确清理顺序。

## 使用前提

1. 自备 frp 服务器（frps + Nginx 反代 + 域名证书），frps 与 frpc **版本一致**。
2. 本机已安装并启用官方 `@dsh-harmony/plugin`（手机协议由它提供，本插件不实现）。
3. 本机放好 `frpc` 可执行文件：推荐 `$DSH_HOME\dsh-tunnel\bin\frpc.exe`，也可指定绝对路径或放入 `PATH`。

## 使用

1. 侧栏底部「公网隧道」按钮 → 打开控制页（与 DSH 同源，复用已登录会话）。
2. 保存 frp 密钥 → 填服务器地址/端口、公网地址、内部代理端口、frp 版本 → 保存。
3. 点「应用」写 DSH 信任配置；如提示需要重启 DSH 则重启。
4. 状态显示「已连接」后，在「手机登录」里取服务地址与访问密钥填入手机 App。

## 明确限制

- 只支持 **Windows** 的「开机自启」（启动文件夹快捷方式；非管理员环境无法注册服务）。
- **DSH 桌面进程未运行时手机不可达**：本插件挂在桌面实例上，不额外启动无界面实例。
- 默认关闭、默认不带任何服务器/域名/密钥；开启后公网可达即等于本机的高权限入口。

## 卸载

停止隧道 → 移除启动项 → 恢复 DSH 默认信任配置 → 插件页移除 → 清理 `$DSH_HOME\dsh-tunnel` 与凭据 `dsh-tunnel:frp-token`。

完整说明、配置项表、排障与安全说明见仓库 `README.md` 与 `docs/SECURITY.md`。
